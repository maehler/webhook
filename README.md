# webhook

![go test](https://github.com/maehler/webhook/actions/workflows/go.yml/badge.svg)
![golangci-lint](https://github.com/maehler/webhook/actions/workflows/golangci-lint.yaml/badge.svg)

Webhook is a simple webhook client. It can send webhook messages and has the ability to retry the request for certain types of errors.

## Install

```bash
go get github.com/maehler/webhook
```
